# 전지적 독자 시점

사용자 제공 7장 디자인과 74초 인터랙션 영상에 맞춘 React 웹사이트입니다.

## 실행

```sh
npm install
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

프로덕션 빌드: `npm run build`. 정적 출력은 `dist/client/`입니다.

## 구현 화면

- 메인: 전체 화면 미디어 자리
- 세계관: 4개 주제, 화면 높이에 맞춘 자동 페이지 분할, 하단 이전/다음 버튼, 인용 문구 전환
- 등장인물: 호버 밝기 변화, 클릭 시 이미지 폭 1.5배 및 인라인 상세, 카테고리별 인물 책장
- 웹소설: 동일 너비의 전 5부 20권 책장, 호버 상승·표지 미리보기, 인라인 상세·권별 목차, 부별 필터 및 책등 이동 화살표
- 영화: 포스터/예고편 화면 전환, 3개 영상 선택 영역, 공식 예고편 및 영화 링크
- 굿즈: 10개 카테고리, 4초 정지 후 1초 자동 슬라이드, 일시정지, 양방향 이동, 모바일 스와이프, 스토어 링크

헤더 내비게이션, URL 해시/뒤로 가기, 데스크톱 휠 화면 이동, PageUp/PageDown, Escape 닫기, 키보드 포커스, 모달 포커스 제한, 동작 줄이기 설정을 지원합니다. 모바일은 콘텐츠 자연 스크롤을 사용합니다.

## 이미지와 영상 연결

요청에 따라 이미지·영상 파일은 넣지 않았습니다. `src/media.js`에서 빈 문자열을 파일 경로로 바꾸면 해당 위치에 표시됩니다.

1. 파일을 `public/media/`에 넣습니다.
2. `src/media.js`에 `/media/example.png` 같은 경로를 적습니다.
3. 예: `heroVideo: '/media/main.mp4'`, `characters: ['/media/dokja.png', ...]`.
4. 책 표지 키: `bookCovers: {'1-1': '/media/part1-vol1.png'}`.
5. 제품 사진: `products: {'피규어': ['/media/a.png', '/media/b.png', '/media/c.png']}`. 현재 카테고리별 3개 슬롯입니다.

로고는 `logo`와 `characterLogo`로 교체합니다. 메인·인물·세계관·영화는 채우기(object-fit: cover), 책 표지·제품은 필요에 맞춰 CSS에서 비율을 조정할 수 있습니다. 제공한 `0920.mov`는 참고 영상이므로 사이트 파일에 포함하지 않았습니다.

## 폰트

로컬 파일로 Pretendard 400/600/700, 나눔명조 400/700/800, MapoDPP를 사용합니다. 사용자가 명시한 '마포DDP'의 설치 파일명이 `MapoDPP.otf`입니다. 외부 폰트 CDN 없이 동작합니다.

## 내용과 제한

출처는 `CONTENT-SOURCES.md`와 굿즈 화면 하단의 출처 모달에서 확인합니다. 웹툰 후기 화면은 삭제했습니다. 상세 첫 권은 사용자 제공 발췌문을 사용하고, 다른 권의 상단은 파트별 소개 요약임을 표기합니다. 목차는 20권 각각에 맞춰 구성했습니다. 구매·회원 기능은 연결하지 않았습니다. 미디어가 비어 있어 원본의 이미지 영역은 검정 공간과 작은 안내 문구로 표시됩니다.

## 검증

`design-qa.md` 및 `qa/`에 데스크톱/모바일 확인 내역과 캡처를 저장했습니다.

## 2026-09-21 수정

웹소설·영화·굿즈 이동 버튼은 왼쪽에서 오른쪽으로 색이 채워집니다. 인물 추가 데이터는 `src/characterCatalog.js`, 권별 목차는 `src/bookDetails.js`, 새 책장 UI는 `src/Shelves.jsx`, 자동 캐러셀은 `src/GoodsCarousel.jsx`에 있습니다. 전체보기는 첨부 분류표에 따른 6개 카테고리·53개 항목입니다. 인물 이미지는 `media.characterCatalog`에 고유 id로 연결할 수 있으며 기존 `media.characters` 슬롯도 유지됩니다. 본편·외전·회차별 항목은 별도 id를 사용합니다.

책 상세는 클릭한 책등의 원래 위치에서 펼쳐집니다. 책·인물 상세는 펼쳐진 전체 영역이 보이도록 책장을 자동 정렬합니다. 굿즈는 왼쪽 카드가 중앙으로 이동하면서 점진적으로 밝아지며, 고정 강조 테두리는 사용하지 않습니다.
